# Bord — versiuni publicate

Aici stau doar versiunile gata de instalat ale **Bord**, launcherul pentru unitatea Android din Dacia Duster.
Codul sursă nu e în acest repo.

Bord își ia singur actualizările de aici (din *Releases*): verifică la câteva ore, iar din
Setări → „Caută actualizări” se poate verifica oricând. Android instalează doar APK-uri semnate cu aceeași
cheie ca Bord, deci un fișier străin nu poate înlocui aplicația.
